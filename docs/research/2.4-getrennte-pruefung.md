## Restrisiken

- **Harte Links unter Windows** (Befund 3): ohne Linkzahl in `std` nicht erkennbar. Ein Paket aus einem Zip-Archiv enthält keine harten Links; gelesen wird nur, was als JSON gültig ist.
- **Race beim Öffnen unter Unix** (Befund 12): setzt einen fremden lokalen Prozess voraus.
- **Reparse-Points unter Windows** (Befund 13): auch harmlose Platzhalter von Cloud-Diensten werden abgewiesen; der Spieler sieht `invalidPath`.
